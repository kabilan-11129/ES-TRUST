# ES Trust Website

Official website for ES Trust, showcasing the trust’s services, activities, gallery, and donation initiatives.

## About the Project

This is a responsive static website built using HTML, CSS, and JavaScript. It provides information about ES Trust and its work supporting education, elders, and women.

## Features

- Home page with organization overview
- About ES Trust page
- Services page
- Education donation page
- Elder care donation page
- Women empowerment donation page
- Contact page
- Image gallery
- Responsive design for desktop and mobile devices

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap
- Font Awesome
- Google Fonts
